## Description
A menu-driven C program for managing municipal
employees, budgets, suppliers, assets and reports.

## Features
- Employee Management
- Budget Management
- Supplier Management
- Asset Management
- Reports
- Search functionality
- Input validation

## How to Compile

gcc main.c employee.c budget.c supplier.c asset.c reports.c -o mfms

## How to Run

./mfms
